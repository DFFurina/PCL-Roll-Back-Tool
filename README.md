# PCL-Roll-Back-Tool

## 简介
一个简单实用的工具，助你将PCL回滚到2.14.0.0版本<br>
作者：BeeNotSting（DFFurina）<br>
bilibili@蜜蜂不想蜇人了

## 实现原理
1. 从Meloong-Git的官方仓库中下载2.14.0.0版本的源代码zip
2. 将其解压后提取其中的“最新正式版.zip”文件
3. 将其替换到用户所选的位置
4. 禁用自动更新（可选）

## 安全性
从PCL官方开源仓库下载代码，不会经过任何改动，直接替换启动器可执行文件<br>
本工具release程序的SHA-256为`2C32F4060360853705581FD7EDAFB2EEF30EC6273C13E012F553FF649EF6848D`<br>
本工具源代码开源，使用MIT许可协议

## 下载
[Windows](https://github.com/DFFurina/PCL-Roll-Back-Tool/releases/latest)

## 使用
1. 启动程序，选择你的启动器文件
2. 勾选“回退后关闭自动更新”
3. 点按“开始：下载并准备回退”按钮，等待期执行完毕
4. 点击“确认执行回退”按钮
5. 开始使用PCL :)))
